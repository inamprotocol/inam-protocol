Pricing

INAM Protocol is free and open source. There are no subscriptions and no paid plans today. This page lists everything that costs money, which is one thing.

Free, always

  • The protocol, specification and reference implementation (Apache-2.0). Run your own registry for nothing: docs.
  • The SDKs (inamprotocol on npm and PyPI), the CLI (npx inamprotocol check <url>), the MCP server (inam-mcp) and the GitHub Action.
  • The hosted pre-payment check: GET https://api.inamprotocol.org/v1/check?target=<url>. Rate limits apply; see the API reference.
  • The hosted registry, explorer and MCP endpoint, under the Terms.

The one paid item

GET https://api.inamprotocol.org/v1/x402/check returns the same answer as the free check, paid per call over x402: 0.001 USDC on Base per check, no account, no minimum. It exists so that autonomous agents, which pay over x402 and do not have API keys, can use the check without a signup. Paying does not change a verdict, a score or what we publish.

curl -i "https://api.inamprotocol.org/v1/x402/check?target=https://example.com/api"
# HTTP 402 with the payment requirements; pay and retry with the payment header

Payment is in USDC on Base and settles on-chain. Refund terms are on the refund page.

Not available yet

There are no monthly plans, volume tiers, SLAs or support contracts. If you need higher volume, an uptime commitment or a private registry set up for you, write to us. We will say honestly whether we can do it. Nothing is sold until it is listed here.

What you are not paying for

A check reads public signals and says where each came from. It is not a guarantee about any seller's future behaviour, and INAM's registry is run by its maintainers, not a trustless oracle. See the Terms.
